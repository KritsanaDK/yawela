# ยาเวลา — Deploy assets

| ไฟล์ | ขนาด | พื้นหลัง | ใช้งาน |
| --- | ---: | --- | --- |
| `app-store-icon-1024.png` | 1024×1024 | ทึบ | App Store และ App Store Connect |
| `google-play-icon-512.png` | 512×512 | ทึบในภาพ, RGBA 32-bit | Google Play Console |
| `yawela-brand-mark-transparent-1024.png` | 1024×1024 | โปร่งใส | Store artwork, press kit และสื่อประชาสัมพันธ์ |

สีหลักของแบรนด์คือ `#147D6F` และสีเสริมคือ `#DDF3EC` กับ `#E99A2F`

- อย่าเติมมุมโค้งให้ Store icons เพราะระบบปฏิบัติการจะตัด mask ให้เอง
- อย่าใช้ไฟล์พื้นโปร่งใสเป็น App Store icon
- ควรแสดงชื่อ “ยาเวลา” เป็นข้อความจริงแยกจาก symbol เพื่อให้ภาษาไทยคมชัดทุกขนาด
